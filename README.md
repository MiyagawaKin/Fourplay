# FourPlay


**在线玩**：https://miyagawakin.github.io/Fourplay/
**中文名**：基基波契数列计算器
**仓库**：https://github.com/MiyagawaKin/Fourplay
**灵感来源**：[itorr/homo](https://github.com/itorr/homo)（恶臭数字论证器）

---

## 这是什么

给它**任何你想要的数字**，它用基波契数列（？） **13、24、78、91** 这四个数组拼出一个算式。

---

## 为什么会出现这种东西

因为作者听到了著名国电制作人78Records的新专辑
**《78:91=6:7》**
https://music.163.com/album?id=398395292&uct2=U2FsdGVkX1992/QHFA3EnBX6/UiyuKmoSaahbKNMSqM=
并且前两首分别是**《78+91=13²》**和**《78+13=91》**
遂试图论证这三个数字的关系，最后加入了24和67发现他们组成了**基基波契数列**
