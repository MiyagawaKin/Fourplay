# 🍆 FourPlay

> **Any number. Four digits. Extra dirty.**
> 任意数字，只用四个数字，加料不加价。

**在线玩**：https://miyagawakin.github.io/Fourplay/
**中文名**：基基波契数列计算器
**仓库**：https://github.com/MiyagawaKin/Fourplay
**灵感来源**：[itorr/homo](https://github.com/itorr/homo)（恶臭数字论证器）—— 学的是它的「手调字典 + 贪心分解 + 输出美化」那套设计。

---

## 这是什么

给它**任何你想要的数字**，它用 **13、24、78、91** 这四个数字拼出一个算式，而这个算式的结果，刚好等于你给的那个数字。

**硬规矩：输出里只会出现 `13` `24` `78` `91` 这四个数字。**

没有平方，没有根号，没有阶乘，没有别的整数，连系数都不许是外来户 —— 需要写个 6，就写成 `78÷13`；需要写个 7，就写成 `91÷13`。整条式子从头到尾只有那四个数字在反复横跳。

**核心理念**：能简单算的，偏要选最花哨的算法算。

## 举个栗子

```
输入：13          输出：13
输入：786         输出：(24×24)+((13+24+78+91)+(((78÷13)-((91-78)-(24-13)))))
```

算一下：

```
24×24 = 576
13+24+78+91 = 206
91-78 = 13，24-13 = 11，(91-78)-(24-13) = 2
78÷13 = 6，6 − 2 = 4
576 + 206 + 4 = 786  ✅
```

再比如 `114514`，dirty 拉到 4：

```
((((91×91)×13+((78×78)+((24×24)+((13×13)+(24+(((91÷13)+91÷13-78÷13)))))))×(91÷13-78÷13))+13-13×13÷13)+24-24
```

`114514 = 2×31×43×43`，其中 `43×43 = 1849` 被它拆成了 `2×31×43×43` 的因数结构再往上拼 —— 这，就是恶臭。

## 玩法规则

| 项 | 说明 |
|---|---|
| **原料** | 只能用 `13` `24` `78` `91`（可重复使用，可任意次） |
| **运算** | `+` `-` `×` `÷` 和括号 —— 就这些，别的全都不许出现 |
| **目标** | 算式的最终结果 = 你给的那个数字 |
| **风格** | 数字自己就是自己就够（`91` 就写 `91`）；想更花哨也有更花哨的写法 |

### 两种风格

- **greedy（默认）**：学 homo 的「字典 + 贪心分解」。先用 `91×91=8281`、`78×78=6084`、`24×24=576`、`13×13=169`、`13+24+78+91=206` 这些花哨小常数去拆，拆不动了换下一个，再把商和余数继续递归拆 —— 摊出来的式子又长又臭。
- **linear**：先解一个 `a×13 + b×24 + c×78 + d×91 = n` 的整数线性组合（扩展欧几里得 + 直解兜底），再把每个系数本身也拆成四个数字 —— 输出更短，但结构更"公式感"。

### Dirty 滑块（0–10）

往上拉，会在**不改变结果**的前提下，给式子套上 `×1`、`+0` 的恒等装饰：

```
×1 → ×(13×13÷13÷13)      +0 → +13-13
      ×(78÷13-78÷13)            +91-91
```

拉满 10 层，式子会膨胀到一两百字符，但 `13×13-13×13` 依然是 0。
